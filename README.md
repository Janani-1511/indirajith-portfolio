# INDIRAJITH T B — Personal Portfolio Website

An **Elegant Beige & Cream – Premium Editorial Design** portfolio for **INDIRAJITH T B**, an Information Technology undergraduate at Dr. N.G.P Institute of Technology, software developer, and AI & IoT enthusiast.

## Design Identity & Palette
- **Background**: Warm Ivory (`#F8F5EF`)
- **Secondary Background**: Soft Beige (`#EDE5D9`)
- **Primary Text**: Deep Charcoal (`#25231F`)
- **Accent**: Muted Olive (`#747B59`)
- **Secondary Accent**: Warm Brown (`#A78668`)
- **Borders**: Soft Taupe (`#D8CEC0`)
- **Typography**: Playfair Display (Serif) & Plus Jakarta Sans (Clean Modern Sans-Serif)

## Folder Structure
- `index.html`: Main editorial portfolio showcase.
- `farmpulse.html`: Featured major project case study page.
- `css/style.css`: Core design system, editorial layouts, responsive grid.
- `css/projects.css`: Specialized project showcase and modal drawer styles.
- `js/script.js`: Interactive navigation, modal popups, scroll reveal, and contact form validation.
- `assets/`: Contains actual uploaded professional photograph (`indirajith-profile.jpg`) and downloadable resume (`Indirajith-Resume.pdf`).
